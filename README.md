# ESP32_WeatherApp
Simple CYD weather app, with digital photo frame and Bluetooth mouse wiggler (keeps PC sesion alive).  Good use for your NM miner.  Zip file includes compiled binary, full Arduino IDE ino file and required files.  Note you need to compile with partition scheme HugeApp no spiffs.
